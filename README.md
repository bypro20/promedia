# ProMedia

Sosyal medya büyüme hizmetleri — Instagram takipçi, beğeni ve daha fazlası.

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcı: http://localhost:3000

## Sayfalar

- `/` — Ana sayfa
- `/instagram-takipci-satin-al` — Instagram takipçi paketleri
- `/siparis-sorgula` — Sipariş sorgulama
- `/telafi-talebi` — Telafi talebi

Vercel ile otomatik deploy (Next.js).
